# Python Cheat Sheet: Parts 1 to 6

## Part 1: Basics

```python
print("a", "b", sep="-")   # a-b    sep goes BETWEEN items
print("hi", end="!")       # hi!    end replaces the new line
age = 25                   # = assigns, == compares
a, b = b, a                # swap two variables
```

- Names: letters, digits and `_`. No spaces, can't start with a number, case-sensitive. Use snake_case.
- Types: `int` 5, `float` 3.5, `str` "hi", `bool` True/False. Check with `type(x)`.
- Conversion: `int("5")` gives 5, `str(10)` gives "10", `int(3.9)` gives 3, `int("abc")` gives ValueError.
- `input()` always returns text: `age = int(input())`.
- Comments start with `#`.
- `7 / 2` is 3.5 (always a float), `7 // 2` is 3, `7 % 2` is 1, `2 ** 3` is 8.
- Order: brackets, `**`, then `* / // %`, then `+ -`.
- Uses of `%`: even/odd (`n % 2 == 0`), divisible checks, last digit (`n % 10`).

## Part 2: Strings

```python
s = "my name is iqra"
s[0]          # 'm'      index starts at 0
s[-1]         # 'a'      -1 is the last
s[1:5:2]      # 'yn'     [start:stop:step], stop excluded
s[::-1]       # reversed
"ab" * 3      # 'ababab'
len("hi")     # 2
"a" in "cat"  # True
```

- `\n` starts a new line. `+` joins, `*` repeats.
- Methods return a NEW string: `upper`, `lower`, `strip`, `replace(old, new)`, `split()` (gives a list), `"-".join(list)`.
- `find` gives the index of the first match, or -1. `count` counts matches.
- `startswith`, `endswith`, `isdigit`, `isalpha` give True or False.
- Strings are immutable: `s[0] = "X"` gives TypeError.
- f-strings: `f"{name} is {age}"`, and `f"{3.14159:.2f}"` gives 3.14 (2 decimals).
- Loop over a string: `for ch in s:`.

## Part 3: Booleans and if

- Comparisons: `==  !=  <  >  <=  >=`. `a < b` is True when a is smaller.
- `and`: both True. `or`: at least one True. `not`: flips it.
- `if / elif / else`: the first True wins and the rest are skipped, so order matters. With `score = 85`, check `>= 80` before `>= 50`.
- Nested `if`: an `if` inside another `if`.
- Falsy: `0`, `0.0`, `""`, `[]`, `{}`, `None`, `False`. Everything else is truthy, including `" "`.
- `"1" == 1` is False (different types). `"5" < 10` gives TypeError.

## Part 4: Functions

```python
def greet(name, greeting="Hi"):     # name, greeting = parameters; "Hi" = default
    return f"{greeting} {name}"

greet("Iqra")                        # "Iqra" = argument
greet(name="Iqra", greeting="Yo")    # keyword arguments (named at the call)
```

- `return` sends the result back AND ends the function. `print` only shows it.
- No `return` means the function gives `None`. `x = print("hi")` leaves x as `None`.
- `return a, b` gives a tuple. Unpack with `x, y = f()`.
- Scope: a variable made inside a function (local) doesn't exist outside it. Using it there gives NameError.
- A function can call another: the inner call runs first.
- `assert add(2, 3) == 5` is silent when it passes and raises AssertionError when it fails. Work out expected values by hand.

## Part 5: Loops

- `for` works over a list, a string, or a `range`.
- `range(3)` is 0,1,2. `range(1, 5)` is 1,2,3,4. `range(1, 10, 2)` is 1,3,5,7,9. The stop is excluded.
- `while` runs until the condition fails. The variable in the condition must change inside the loop, or it never ends.
- `break` leaves the loop now. `continue` skips to the next round.

```python
total = 0                    # accumulator: start BEFORE the loop
for x in nums:
    total += x

count = 0                    # counter
for x in nums:
    if x % 2 == 0:
        count += 1

found = False                # flag: remembers whether something happened
for x in nums:
    if x == target:
        found = True

for x in nums:               # early return: leave as soon as you know
    if x == target:
        return True
return False
```

- Nested loops: the inner loop runs fully for every round of the outer loop.
- Digits: `n % 10` is the last digit, `n // 10` removes it.
- Prime: at least 2, and no number from 2 to n-1 divides it.
- Palindrome: reads the same backwards (121).
- Factorial: 5! = 5*4*3*2*1 = 120 (accumulator starts at 1). Fibonacci: 0, 1, 1, 2, 3, 5 (each is the sum of the previous two).

## Part 6: Lists

```python
a = [3, 1, 2]
a[0]; a[-1]; a[1:3]; len(a)
a.append(5)         # add at the end
a.insert(0, 9)      # add at index 0
a.remove(2)         # remove by value
a.pop()             # remove the last item AND return it
a.index(3)          # position of the first 3
a.count(3)          # how many 3s
a.extend([7, 8])    # adds each item. append([7, 8]) adds ONE item (the list).
```

- Lists are ordered and mutable.
- In-place methods return None: `append`, `insert`, `extend`, `remove`, `sort`, `reverse`. Never write `a = a.sort()`. (`pop` is the exception.)
- `sorted(a)` returns a NEW sorted list. `a.sort()` changes `a`.
- `a.reverse()` is in place. `a[::-1]` is a new list.
- Aliasing: `b = a` shares one list. `b = a[:]` makes a copy.
- Loop by value: `for x in a`. Loop by index: `for i in range(len(a))`.
- `+` joins two lists into a new one.
- Swap: `a[i], a[j] = a[j], a[i]`.
- Reverse in place: `for i in range(len(a) // 2): a[i], a[-1 - i] = a[-1 - i], a[i]`.
- Running sum: keep `total`, then `append(total)` each round.

## Extras

**Errors:** SyntaxError (typo in the code), IndentationError (spacing), NameError (name not defined), TypeError (wrong type, like `"5" < 10`), IndexError (index too big), ZeroDivisionError, ValueError (like `int("abc")`). Read a traceback from the bottom up: the error type, then the line number.

**Interview answer, 6 steps:** restate, clarify, plan aloud, code, test aloud, complexity.

**Edge cases:** empty, one item, duplicates, negatives.

**Big-O:** `a[0]` and `len(a)` are O(1). One loop is O(n). A loop with O(n) work inside it is O(n²). Two loops one after the other add up: O(n + m). Space counts only the extra memory you create.

**LeetCode:** keep `self`, use their parameter names, `return` and don't `print`, no asserts. Don't name variables `sum`, `max`, `min` or `input`.

**Git:** `status`, `add <file>`, `commit -m`, `push`. Don't use `git add -A` when unrelated files changed. `commit --amend` only changes the latest commit. After amending a pushed commit, use `push --force-with-lease`.
